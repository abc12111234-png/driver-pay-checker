# driver-pay-checker

トラックドライバーのための給料チェッカー（残業代・最低賃金・拘束時間の目安）。

サイト：https://abc12111234-png.github.io/driver-pay-checker/

給与明細とその月の働き方を入れると、次のことを目安で確かめられます。

- 残業代の不足（時間外・深夜・法定休日、60時間超の5割増、歩合給・日給制・固定残業代に対応）
- 最低賃金（令和8年度の地域別最低賃金と発効日）
- 拘束時間・休息期間・430（トラック運転者の改善基準告示、2024年4月適用）
- 会社の記録（明細の勤怠）と自分の記録の差
- 同じ車種の平均との差（月の給料・実働・時給・年齢）

入力した数字はブラウザの中だけで計算し、どこにも送信しません。

勤務の記録（`log.html`）では、始業、休憩、荷待ち・待機、終業をボタンで記録すると、拘束時間（始業から24時間）と休息期間を改善基準告示で判定し、1か月の総労働・時間外・深夜・法定休日・拘束の時間を出します。その月の時間は、ボタンひとつで給料チェッカーに渡せます。会社の記録とは別に残す自分の記録として、場所（書き込みと、オンにしたときだけ押したときのGPS）、乗った車両（車種・車番）と始業・終業のメーター（その日と月の走行距離を出す。始業・終業を押すと入力の画面が開く）、書いた日時つきのメモ、あとで直した・消した記録の履歴も残し、その日の記録を自分あてに送る機能、バックアップ（JSON）とCSVの保存があります。記録はブラウザの中（ローカルストレージ）にだけ保存します。

適性・進路診断（`shindan.html`）では、はい・いいえで働き方の好みと、いま持っている免許を答えると、合いそうな働き方（宅配・小口、ルート配送・地場、増トン・大型の地場、大型の長距離、トレーラー）、要る免許、取る方法（教習の時限、合宿の最短日数と料金の範囲、通学の料金）、受けられるか（年齢・経験、受験資格特例教習）、年収の目安を出します。答えはブラウザの中だけで使います。

広告（A8.netの紹介）は `ads.js` にまとめています。診断では、質問の前（「診断を始める」の下）と結果のすぐ下の2か所にだけ出し、待たせて見せる形にはしません。都道府県や年齢に条件がある紹介は、結果のところで都道府県と年齢を入れてもらい、対象の人にだけ出します。A8のタグと紹介文を貼るまでは何も出ません（`shindan.html?ad=preview` で見本を表示）。

## ファイル

- `index.html` ツール本体
- `log.html` 勤務の記録
- `shindan.html` ドライバー適性・進路診断
- `about.html` 運営者情報
- `privacy.html` プライバシーポリシー・免責事項
- `log.webmanifest`、`icons/` 勤務の記録をホーム画面に入れるための設定とアイコン
- `ads.js` 広告（A8.netの紹介）の中身と、出してよい人の条件（都道府県・年齢など）
- `sw.js` 電波のないところでもページを開けるようにする（ページのファイルだけを保存し、記録は含まない）
- `tests/test-log.js` 勤務の記録の計算のテスト（`TZ=Asia/Tokyo node tests/test-log.js log.html`）
- `tests/e2e-log.js` 勤務の記録のブラウザでの確認（Playwright。使い方はファイルの先頭）
- `tests/test-shindan.js` 適性・進路診断の判定のテスト（`node tests/test-shindan.js shindan.html`）
- `tests/e2e-shindan.js` 適性・進路診断のブラウザでの確認（Playwright。使い方はファイルの先頭）
- `tests/test-ads.js` 広告を出してよい人の判定と、`ads.js` の中身の確認（`node tests/test-ads.js`）

## データの出典

- 最低賃金：厚生労働省「地域別最低賃金の全国一覧」（令和8年度）
- 拘束時間の基準：トラック運転者の改善基準告示（2024年4月適用）
- 車種の平均：全日本トラック協会「2024年度版 トラック運送事業の賃金・労働時間等の実態」
- 平均的な労働時間：日本労働研究雑誌（2026年）
- 適性・進路診断：道路交通法施行規則（免許の区分、別表第四の教習時限）、警察庁（受験資格特例教習）、合宿免許ネクストの料金の集計（2026年10月9日更新）、教習所の料金表、全日本トラック協会「2025年度版 トラック運送事業の賃金・労働時間等の実態」、厚生労働省（教育訓練給付）

計算結果は目安です。法律上の判断や個別の相談の代わりにはなりません。
