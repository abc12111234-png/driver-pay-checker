# driver-pay-checker

トラックドライバーのための給料チェッカー（残業代・最低賃金・拘束時間の目安）。

サイト：https://abc12111234-png.github.io/driver-pay-checker/

給与明細とその月の働き方を入れると、次のことを目安で確かめられます。

- 残業代の不足（時間外・深夜・法定休日、60時間超の5割増、歩合給・日給制・固定残業代に対応）
- 最低賃金（令和8年度の地域別最低賃金と発効日）
- 拘束時間・休息期間・430（トラック運転者の改善基準告示、2024年4月適用）
- 会社の記録（明細の勤怠）と自分の記録の差
- 同じ車種の平均との差（月の給料・実働・時給・年齢）

入力した数字はブラウザの中だけで計算し、どこにも送信しません。

勤務の記録（`log.html`）では、始業・休憩・荷待ち・終業をボタンで記録すると、拘束時間（始業から24時間）と休息期間を改善基準告示で判定し、1か月の総労働・時間外・深夜・法定休日・拘束の時間を出します。その月の時間は、ボタンひとつで給料チェッカーに渡せます。会社の記録とは別に残す自分の記録として、場所（書き込みと、オンにしたときだけ押したときのGPS）、書いた日時つきのメモ、あとで直した・消した記録の履歴も残し、その日の記録を自分あてに送る機能、バックアップ（JSON）とCSVの保存があります。記録はブラウザの中（ローカルストレージ）にだけ保存します。

## ファイル

- `index.html` ツール本体
- `log.html` 勤務の記録
- `about.html` 運営者情報
- `privacy.html` プライバシーポリシー・免責事項
- `tests/test-log.js` 勤務の記録の計算のテスト（`TZ=Asia/Tokyo node tests/test-log.js log.html`）
- `tests/e2e-log.js` 勤務の記録のブラウザでの確認（Playwright。使い方はファイルの先頭）

## データの出典

- 最低賃金：厚生労働省「地域別最低賃金の全国一覧」（令和8年度）
- 拘束時間の基準：トラック運転者の改善基準告示（2024年4月適用）
- 車種の平均：全日本トラック協会「2024年度版 トラック運送事業の賃金・労働時間等の実態」
- 平均的な労働時間：日本労働研究雑誌（2026年）

計算結果は目安です。法律上の判断や個別の相談の代わりにはなりません。
